# 🎯 Jogo do Número Secreto

Um jogo desenvolvido com **HTML, CSS e JavaScript** onde o objetivo é adivinhar um número secreto sorteado aleatoriamente entre 1 e 100.

![Tela do Jogo](Numero-Secreto-Alura.jpg)

## 📋 Sobre o Projeto

O Jogo do Número Secreto desafia o jogador a descobrir um número aleatório através de tentativas sucessivas.

Após cada palpite, o sistema informa se o número secreto é maior ou menor que o valor informado, ajudando o jogador a encontrar a resposta correta.

O projeto também conta com um mecanismo que evita a repetição de números sorteados até que todos os números disponíveis tenham sido utilizados.

---

## 🚀 Funcionalidades

* Sorteio aleatório de números entre 1 e 100.
* Validação de entrada do usuário.
* Dicas indicando se o número secreto é maior ou menor.
* Contador de tentativas.
* Reinício da partida sem recarregar a página.
* Controle para evitar repetição de números sorteados.

## 🎮 Como Jogar

1. Digite um número entre **1 e 100**.
2. Clique no botão **Chutar**.
3. Observe a dica exibida na tela.
4. Continue tentando até encontrar o número secreto.
5. Após acertar, clique em **Novo Jogo** para iniciar uma nova partida.
